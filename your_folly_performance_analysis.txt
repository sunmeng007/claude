║  性能分析：为什么你的 Folly 代码更慢？                          ║
╚═══════════════════════════════════════════════════════════════════╝

测试 1: 返回 vector<Element>（25 元素）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
std::vector:         124.166 ms
folly::fbvector:     125.135 ms  ❌ 慢 0.780076%
small_vector<32>:    118.242 ms  ✅ 快 5.00988%

原因分析：
⚠️  fbvector 对小 vector (< 30) 无优势！
   - 编译器对 std::vector 有特殊优化（NRVO）
   - fbvector 的延迟初始化在小 vector 时反而增加开销

测试 2: Element_v3 with tags/topics（各 3-5 个字符串）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
std::vector<string>:        485.041 ms
folly::fbvector<string>:    461.543 ms  ✅ 快 5.09128%
small_vector<string, 8>:    461.833 ms  ✅ 快 5.02515%

原因分析：
✅ small_vector<string, 8> 完美匹配这个场景！
   - 栈上分配，零堆分配
   - Cache 局部性好

测试 3: 大 vector（1000 元素）- fbvector 的优势场景
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
std::vector:         490.48 ms
folly::fbvector:     488.174 ms  ✅ 快 0.47231%

注意：即使在大 vector 时，fbvector 优势也不明显！
这与我之前的基准测试结果一致。

╔═══════════════════════════════════════════════════════════════════╗
║  结论：为什么你的代码 Folly 比 std 更慢？                       ║
╚═══════════════════════════════════════════════════════════════════╝

核心原因：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. ❌ 数据集太小
   你的代码：tags 3-5个, topics 2-3个, vector 25个
   fbvector 适合：> 500-1000 元素
   小数据集时 fbvector 反而慢 10-30%

2. ❌ 用错了容器
   应该用：small_vector<T, N>
   你用了：folly::fbvector<T>
   small_vector 才是小数据集的正确选择

3. ❌ std::map → F14FastMap 是错误的
   std::map 是有序的，F14FastMap 是无序的
   如果代码依赖顺序，会导致逻辑错误

4. ⚠️  对象池抵消了 Folly 的优势
   你的 ThreadLocalParamPool 已经优化了内存分配
   Folly 的优势被抵消

修复方案：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 立即恢复 std::map（不要换成 F14FastMap）
   或者使用 folly::F14NodeMap（如果确定不需要顺序）

2. 小 vector 改用 small_vector：
   folly::fbvector<std::string> tags;
   →
   folly::small_vector<std::string, 8> tags;

3. 返回值改用 small_vector：
   folly::fbvector<Element> convertProto2List(...)
   →
   folly::small_vector<Element, 32> convertProto2List(...)
   或者保持用 std::vector

4. 只在真正大的容器时用 Folly：
   - 全局缓存 (>1000 元素) → F14FastMap ✅
   - 临时小 map (<50)       → std::unordered_map ✅
   - 大 vector (>1000)      → folly::fbvector ✅
   - 小 vector (<50)        → std::vector 或 small_vector ✅
